Database Schema Cheat Sheet (click to open/close)

Two tables. Every passenger has a portId that points at a row in ports — that link is what you join on. A value of 1 in survived means the passenger lived; 0 means they died. The age and cabin columns can be NULL (missing).

Before you start

Load the dataset into PostgreSQL using psql:

CREATE DATABASE titanic;
\i titanic.sql
\r clears the terminal buffer- sometimes needs resetting.
Supress annoying log messages: SET client_min_messages = 'warning';

Using psql

Open a terminal and connect to the database, then run your queries:

psql -U postgres -d sqltitanic

Handy psql commands: \dt lists tables, \d passengers describes a table, \x toggles wide output, \q quits.

Typing a query that ends without a semicolon will wait for more input — finish with ; and press Enter.
